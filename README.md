## Aplicación

La versión más reciente de la aplicación puede encontrarse en la pestaña [releases](https://github.com/ValeSolArroyo/TP2-Catan/releases/tag/v1.0.0) y ejecutarse en Linux, Windows o Mac de esta forma:

```bash
$ java -jar catan.jar
```
